HADDOCK3 对接蛋白-蛋白 · 蛋白-配体 · 蛋白-多糖

独立 HADDOCK3 作业：按下列参数生成 haddock.cfg，保留输入结构、约束、日志、CAPRI 表和最佳模型。HADDOCK score 是任意单位（a.u.，越低越好），不是结合自由能；没有实验参考结构时不会把 CAPRI RMSD 当作验证。

蛋白-配体请填配体名称或 SMILES；蛋白-多糖请填含糖链的 PDB（可写 1LMQ:B）。留空链号时自动选择首个合适链。

默认 20 个刚体采样，运行时间取决于体系与核数；配体需要 RDKit 生成 3D 结构。作业步骤和文件会记录在下方任务卡片。

01 · 快速开始

  1. 服务器启动后，浏览器打开 http://服务器IP:8010；手机与服务器同一 Wi-Fi 时用局域网 IP。
  2. 登录后先在“设置”修改演示密码。公网访问必须使用 HTTPS，不要直接端口转发明文 HTTP。
  3. 在“设计工作台”选择自动/食品/生物设计，输入目标并生成候选。
  4. 点击“证据图谱”检查推理链；点击“运行机制计算”进入 Vina/MD/QM 作业。
  5. 在“在线证据”底部检索本地 OA 文献；在“模型实验室”导入自己的实测数据。

远程访问：推荐 Cloudflare Tunnel、Tailscale 或带 HTTPS 的反向代理。具体步骤见服务器 docs/DEPLOYMENT.md。

02 · 设计工作台怎么读

候选是可比较的数字原型，不是已经做出来的产品。综合评分是加权决策指数，不是成功概率。约束通过只表示模型内的规则通过，仍需实测。

食品模式展示配方占比、配料角色、相互作用与工艺；生物模式展示蛋白/化合物、保护剂组合、Tm、保留率、亮度与光谱。

at_risk 表示筛选区间跨过边界，必须做验证实验。所有区间都是假设，不是统计置信区间。

报告不会用随机数挑选候选；每个候选都能追溯到数据版本、规则和参数指纹。

03 · 证据图谱

节点代表设计、候选、配料/保护剂、推理步骤、约束、文献或数据源；边代表使用、支持、相互作用或下一步。滚轮/双指缩放，拖拽平移，点击节点查看详情。

“类型着色”区分节点角色；“连接度着色”让枢纽节点更醒目。数据源节点可打开原始数据库；文献节点来自 curated prior，不等于临床证据。

04 · 机制计算与 3D

Vina 给出对接姿态与打分；GROMACS 短 MD 只检查局部稳定性；CP2K 只计算小体系电子结构。三者都不是生产级自由能、成药性或安全结论。

3D 查看器支持 PDB、PDBQT 多构象、GRO；可切换卡通/主链/球棍/空间填充，按元素/链/深度着色，显示配体与单字母序列。点击原子查看残基，导出当前视图 PNG。

从计算结果中可直接打开 receptor.pdb、poses.pdbqt、md.gro；多构象文件会显示构象选择器。

05 · 模型实验室

先导入 CSV/JSON，明确标记实测、文献、模拟或合成来源。训练使用交叉验证；合成数据必须显式勾选。贝叶斯优化只会在训练范围内搜索，不会外推。

预测区间与 EI 是统计辅助，不是实验保证。回灌实测会更新数据哈希与模型版本。

06 · 文献库与标签

本地库当前含 10,000 篇 Europe PMC OA 元数据、25,000+ 文本块和 Obsidian 笔记。检索使用 SQLite FTS5/BM25，不需要联网。

标签映射：标题/摘要规则 → topic；MeSH → mesh/…；作者关键词 → keyword/…；化合物 → chemical/…。Obsidian 笔记位于服务器数据目录的 obsidian/<year>/。

07 · 故障排查

手机打不开：确认地址是电脑局域网 IP 和 8010 端口；127.0.0.1 只指手机自己。检查防火墙与同一 Wi-Fi。

Internal Server Error：查看 logs/bioforge.log 或 logs/server-v3.log；生物设计缺少 ID 的问题已在 3.2 修复。

计算失败：在“机制计算”展开本地软件接口，检查 Vina/GROMACS/CP2K 路径；超时只保护单步。

数据备份：备份 runtime/、Lab 数据库与文献数据目录；不要把 runtime/.token 或密码提交到仓库。

08 · 数据库与来源

主库为 PostgreSQL 16 + pgvector；当前已同步 10,000 条文献元数据、25,062 个文本块、48,544 个图谱实体和 76,954 条边。页面“资源库”列出全部公开/许可来源、许可说明和官方跳转链接。

pgvector 字段已建立但尚未生成嵌入向量；文献检索当前使用 PostgreSQL 全文索引，失败时回退到本地 SQLite FTS5。开放获取解析只调用 Crossref、Europe PMC、Unpaywall 等合法接口。

Sci-Hub、付费墙绕过、验证码规避和未授权批量下载不提供。机构资源请使用学校官方 SSO/EZproxy/CARSI 登录；软件不收集账号密码。

09 · 必须保留的边界

  • 配方、模型、对接、MD、QM 和文献检索均为研究与设计决策支持。
  • 不构成食品/药品/医疗器械合规、安全性、有效性或临床结论。
  • 合成/模拟数据不能替代湿实验；文献标签不能替代人工阅读。
  • 公网部署前必须修改默认密码、启用 HTTPS、限制访问并做好备份。
